# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, race condition, or concurrency bypass in Cappd, please report it responsibly:

1. **Do not open a public issue.**
2. Submit a private report via [GitHub Security Advisories](https://github.com/y9ndra/cappd/security/advisories/new).
3. Include:
   * A clear summary of the issue
   * Steps to reproduce or a minimal proof-of-concept script
   * Expected vs. actual behavior under concurrency

We will acknowledge receipt within 48 hours and work with you to test and release a patch before any public disclosure.
